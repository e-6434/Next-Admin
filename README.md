# 🧭 Next.js Admin Dashboard

یک داشبورد مدیریتی حرفه‌ای ساخته‌شده با **Next.js**، طراحی مدرن و ساختار تمیز برای توسعه سریع پنل‌های مدیریت و اپلیکیشن‌های وب.

---

## 🚀 ویژگی‌ها
- ⚡ ساخته‌شده با [Next.js 14+](https://nextjs.org/)
- 🎨 طراحی مدرن با [Tailwind CSS](https://tailwindcss.com/)
- 📦 ساختار فولدر‌بندی تمیز و قابل توسعه
- 🔐 صفحات احراز هویت (Login / Register)
- 📊 چارت‌ها و نمودارها (Chart.js / Recharts)
- 🌙 تم تیره و روشن (Dark/Light Mode)
- 🧱 کامپوننت‌های آماده برای UI

---
